# Windows 在线阅读与高刷玻璃改造

用户已批准：升级引擎，改造现有工程。保留本地 TXT/EPUB、书架、书签、进度与阅读排版，新增应用内联网搜索、详情及可读章节，采用 iOS 27 Liquid Glass 方向，兼容 60/120/144Hz。朋友使用 Windows，最终实机验收由朋友运行交付包完成。

## 架构与连接

保持 NovelRepository、OfflineNovelRepository、NovelFeedController 的现有边界。新增独立官网传输层、HTML 解析器和 Windows 在线仓库；只读取官网正常提供的页面。搜索有防抖、分页及过期结果隔离；详情、目录、正文沿用现有阅读器和缓存。登录要求、访问验证、服务限流、内容不可读和网络错误分别呈现，不将服务提示缓存成正文。访问验证由用户在官网页面完成，随后重试原操作；不自动处理 CAPTCHA。

## 引擎与渲染

目标 SDK 为 Flutter 3.47.0 稳定版，核对官方 tag 与实际 SDK；配置文件、构建脚本和 CI 使用同一版本。Windows 使用 Impeller，shader filter 不可用或初始化失败时保留有边界的磨砂回退。旧的 Windows 强制本地模式改为可由用户切换的阅读器模式。原始书籍和持久化数据不作破坏性迁移。

## 视觉方向

保留轻小说档案式书架和正文宋体。控件采用透亮中性玻璃、细边缘折射与适度阴影；导航和搜索框使用悬浮胶囊，菜单与页面切换使用连贯的伸展/弹性响应。玻璃仅位于工具层，正文保持对比度。透明度可调，深浅主题、键盘焦点、减少动态效果设置均保留。避免对全部书籍同时应用实时玻璃滤镜。

## 高刷与性能

Windows 动画按引擎 vsync 和当前显示器刷新率运行，不修改系统显示设置。兼容 60/120/144Hz，跨显示器或刷新率变化后更新状态。移除仅 Android 可用的刷新率调用在 Windows 的错误路径。性能采集同时记录刷新率、构建/光栅耗时分位数、超预算帧数，区分 FrameTiming 和真实呈现帧率。120Hz 帧预算 8.33ms，144Hz 为 6.94ms。通过 profile/release 录制书架拖动、翻页、滚动、菜单开合；实测前不声称达标。

## 验证与交付

每个新增行为先用最小测试确认当前失败再实现。覆盖真实 HTML 解析、请求参数、分页、验证/限流/不可读、章节文本/图片、刷新率变化与性能预算、入口导航、玻璃回退和本地导入回归。完成静态检查、单元/组件测试，保留 Windows 原生集成测试并补在线路径与性能场景。最终交付对应源码、Windows 构建入口、可用的 Windows 程序包和朋友可直接操作的验收说明；构建和实测证据分别记录。Mac 测试不能替代 Windows GPU 和实际呈现验证。
